# Desafio Minimal API - DIO (.NET 10)

Projeto desenvolvido como parte do desafio do Bootcamp de .NET da Digital Innovation One (DIO). O objetivo foi criar e estruturar uma Minimal API em .NET, integrando a documentação dos endpoints com Swagger.

## Tecnologias Utilizadas
* .NET 10
* C#
* Swashbuckle.AspNetCore (Swagger)
